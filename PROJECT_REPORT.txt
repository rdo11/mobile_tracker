MOBILE TRACKER — PROJECT REPORT
================================
Updated: 2026-08-22 (M5 MacBook Pro era)

WHAT THIS PROJECT IS
--------------------
A privacy-first, fully-local dashcam vehicle recognition system. An iPhone
(Iriun wireless webcam) streams 1080p footage to an Apple M5 MacBook Pro
(24GB unified memory). A FastAPI/WebSocket dashboard (localhost:8500) runs:

  1. YOLOv8n detection + ByteTrack tracking (~27 FPS sustained on replay,
     detect imgsz 320, detect_scale 0.5, every 2nd frame)
  2. Local ResNet50 make/model classification (285+ classes, MPS, ~7 ms)
     running on a background worker — never blocks the video path
  3. Coarse labels (Pedestrian / Cyclist / Motorbike / Bus / Truck) straight
     from YOLO class names — zero model/API cost
  4. HSV color analysis (synchronous, ~1 ms)
  5. ANPR: plate YOLO + EasyOCR on a background worker, plate country guess
     (DE/CZ/SK/AT/PL/HU/IT/ES/UK/BE/FR/SE/NL/CH), plate-based re-ID memory
     with TTL, GDPR blur pipeline (blur_plates toggle + require_blur gate)
  6. Replay mode (source = mp4 file) for development without driving

Design philosophy: HONESTY OVER HALLUCINATION. Distant cars (box < 90 px or
ROI < ~12000 px^2) and predictions below min_display_conf (0.45) show
"Unknown" instead of confident wrong guesses.

MACHINE MIGRATION (M2 Air -> M5 Pro) & MEASURED SPEEDUPS
--------------------------------------------------------
The project moved from a base M2 MacBook Air (8GB, fanless) to an M5 MacBook
Pro (24GB). Measured on identical workloads:

  Workload                     M2 Air            M5 Pro          speedup
  --------------------------   ----------------  --------------  -------
  ResNet50 inference           ~40 ms            ~7 ms           ~5-6x
  YOLOv8n det (1920px frame)   ~86 ms @imgsz480  13 ms @320      ~7x eff.
  Live pipeline                ~25 fps, freezes  ~27-28 fps cap  stable
  r50 fine-tune epoch          IMPOSSIBLE*       ~9-11 min       n/a

  * M2-era torch 2.13 MPS silently corrupted gradients in multi-class
    training (the original debugging saga). On the M5, MPS trains CORRECTLY:
    validated with the 2-class Golf-vs-Polo protocol (loss 0.74 -> 0.35,
    accuracy climbing normally) before trusting any run.

  vs cloud GPUs: RunPod RTX 2000 Ada does this job's epochs ~2-4x faster in
  raw GPU time, but data upload/setup/checkpoint-download overhead makes
  end-to-end time similar for small jobs (<1 h GPU), while costing $0.10-0.35
  per session vs ~$0.02 electricity locally. Rule of thumb adopted:
  local M5 for short fine-tunes; RunPod 4090-class only for big jobs.

THE DATASET (BUILT FROM SCRATCH, STILL GROWING)
-----------------------------------------------
- ~10.8k web images scraped from Wikimedia Commons (wikimedia_scraper.py;
  polite rate limits, generation merging: Golf VII -> Golf, E90 -> 3 Series)
- YOLO-filtered to 9,521 clean images (10% noise dropped)
- Real-domain crops, three sources:
    a) own drives (Iriun recordings) via label_drive.py / extract_crops.py
    b) YouTube EU dashcam drives (clean footage, no burned-in overlays!)
       via extract_crops.py — distance-bucketed (far/mid/near), sharpest
       crop per unique tracked car, NO API calls during extraction
    c) labeled by Gemini/DeepSeek batch vision calls (50 crops/request)
       into storage/dataset/dashcam_raw/<Make_Model>/
- As of 2026-08-22: 578 labeled real crops across 125+ classes
- build_merged.py assembles the train set reproducibly:
    filtered/web union -> canonicalize (accent-fold, case-fix SEAT,
    variant folding Combi/SW/ST/Avant/Touring/Sportback/... -> base model,
    aliases Kia cee'd->Ceed, Kona Electric->Kona, Enyaq iV->Enyaq,
    Crossland X->Crossland, generation digits/letters Golf_7->Golf)
    -> hardlink web images + inject real crops x30 -> storage/dataset/train_v6
    -> hold out every Nth real crop as dashcam_val (NEVER trained on)
- Current build: 305 classes / ~25.8k train images / 56-crop real holdout

THE DEBUGGING SAGA (continued on the M5)
----------------------------------------
6. THE SILENT KILLER — AsyncClassifier availability bug: the async classify
   worker snapshotted classifier.available AT CONSTRUCTION TIME, but it is
   built BEFORE load_engines() loads the model -> frozen False forever ->
   EVERY live classification request was silently dropped. The local model
   had never actually classified anything live; Land Rover-style outputs
   users saw were the old Grok fallback masking it. Fix: `available` is now
   a live property delegating to classifier.available.
7. LAND ROVER COLLAPSE QUANTIFIED: the deployed v5 model scored only 31%
   top-1 on the new honest holdout (dashcam_val) despite 95.6% "val_acc"
   (oversampled = memorized). Root causes: domain gap + orphaned crops.
8. LABEL FRAGMENTATION: Gemini had written 'Citroen_C3' AND 'Citroën C3',
   'Seat Ibiza' AND 'SEAT_Ibiza', estate variants (Combi/SW/ST/Avant...) as
   separate folders — 54 dirs / ~89 crops stranded outside canonical classes.
   Fixed by canon() in build_merged.py + fold_label() in label_crops.py at
   SAVE time (prevents recurrence).
9. RETRAIN ON M5 (v6): head-extend 252 -> 285 classes (fc-strip patch
   re-applied after the transfer lost it), 8 epochs, batch 128, lr 3e-4,
   MPS. Result on the honest holdout: top-1 31% -> 53.3%, top-5 70%.
   Zero Land Rover bias in replay of the 13-min EU drive.
10. PEDESTRIAN LABELS: person/bicycle were excluded from the coarse-label
    branch -> showed "Unknown". Fixed: all non-car classes get their coarse
    YOLO label regardless of box size (distant pedestrians included).
11. DEEPSEEK VISION QUIRK: deepseek-v4-flash-vision-exp has THINKING MODE ON
    BY DEFAULT at effort=high; max_tokens gets consumed by reasoning_content
    and `content` returns EMPTY. Fix: "thinking": {"type": "disabled"} in the
    payload (+ docs confirm base64 image_url batching format we use).
12. macOS PYTHON 3.14 GOTCHAS: DataLoader fork workers randomly segfault
    (cv2+fork) killing training -> num_workers=0 for MPS (4 kept for CUDA).
    EasyOCR first-run download stalls -> fetch craft_mlt_25k/english_g2 zips
    manually into ~/.EasyOCR/model/. Camera access needs explicit macOS TCC
    permission (use Iriun phone instead of Mac webcam).
13. REPLAY PACE TRAP: recordings made by the app have tracking boxes BURNED
    IN (recorder writes the annotated buffer). Replays work, but such footage
    is contaminated for future crop mining — prefer clean external footage
    (YouTube drives) for training data. TODO: write clean frames to disk,
    annotate only the streamed copy.
14. LABEL CONTRADICTIONS (2026-08-23): repeated API labeling runs had saved
    the SAME crop file under DIFFERENT class folders (e.g. t1639 in both
    Mercedes-Benz_GLA and Skoda_Enyaq_iV) — direct contradictions, x30
    oversampled. Cross-checking every crop with a SECOND provider
    (cross_check_labels.py) quarantined 201 of 578 crops (!) into
    storage/dataset/quarantine/. v7 (trained on noisy 305-class set) LOST
    top-1 vs v6 on the holdout (36% vs 49%) despite better top-5 — noise
    hurts more than data volume. Fixes: global filename dedupe in
    label_crops.py (refuses contradictory saves), two-provider verification,
    v8 retraining on the cleaned 276-class set.

INFRASTRUCTURE LESSONS
----------------------
- Validate ANY new training backend with the cheap 2-class test before
  trusting it (this protocol cleared the M5 where it condemned the M2)
- Oversampled val_acc is marketing; only held-out REAL crops tell truth
- API vision models differ in subtle contract details (DeepSeek thinking
  mode eats content; xAI wants reasoning_effort=low) — read provider docs
- Keep API keys in .env only; rotate any key ever pasted into chat history
- Label normalization belongs at WRITE time (label_crops.fold_label), not
  just merge time — datasets stay clean forever after

POD SSH STABILITY PLAYBOOK (final version)
------------------------------------------
- Account Settings -> SSH Keys must contain agent pubkey BEFORE renting.
- Always use "SSH over exposed TCP" line (supports scp); gateway rejects.
- Port changes after every restart — re-read from dashboard/API.
- sshd rate-limits rapid attempts: ONE attempt then wait minutes.
- ControlMaster persistent connection prevents repeat auth flaps:
    ssh -o ControlMaster=auto -o ControlPath=/tmp/cm -o ControlPersist=1800 ...
- scp uploads can truncate on session death: VERIFY remote size == local
  size; re-push individual files if mismatch.
